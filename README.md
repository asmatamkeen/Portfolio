A high-performance, cinematic personal portfolio built with React 19, Vite, Tailwind CSS v4, Framer Motion, and AOS. Designed to highlight core computer science projects, algorithmic problem-solving capabilities, technical leadership, and verified credentials.

---

## 🌟 Features & Highlights

- **Interactive Cinematic Hero**: Video background with custom "Play Reel" controls and floating social navigation.
- **Lanyard ID Badge Section**: Custom CSS drop-and-bounce animation showcasing core tech stack icons (Python, Java, C/C++, SQL, OpenCV).
- **Scroll-Driven Process Path**: Animated SVG dashed line path powered by Framer Motion `useScroll` + `useSpring` with dynamic card highlighting.
- **Featured Projects Grid**: Highlighted cards with tech tags, live demo buttons, and GitHub repository links (Score Ranker, AI OMR Sheet Corrector, SkinSync Database, Secure C Login, Currency Converter).
- **Interactive Timeline**: Executive leadership and technical mentorship track in IEEE chapters.
- **Verified Certifications**: Modal & direct PDF viewer integration for verified credentials (`Certificates.pdf`).
- **Contact Integration**: Glassmorphism contact section with built-in input validation and email draft fallback.
- **Fully Responsive**: Mobile slide-down navigation menu and adaptive grid layouts.

---

## 🛠️ Tech Stack

- **Frontend Core**: React 19, Vite 8, HTML5, JavaScript (ES2026+)
- **Styling**: Tailwind CSS v4, Custom Keyframes, Organic SVG Section Dividers
- **Animations**: Framer Motion 12, AOS (Animate On Scroll) 2.3
- **Icons & Media**: Inline Crisp SVGs, HTML5 Video API
- **Deployment**: Compatible with Vercel, Netlify, and GitHub Pages

## 🚀 Quick Start & Installation

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18+ recommended) installed.

### 1. Clone the repository
```bash
git clone https://github.com/asmatamkeen/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 4. Build for production
```bash
npm run build
```
